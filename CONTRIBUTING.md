# Contributing

Start with a concrete missing source, reproducible failure or improvement to a discovery/adoption workflow. Include public source links and licence scope. Do not submit private project details, credentials or real agent memory in issues, tests or pull requests.

Use Node.js 24+, `npm ci`, then `npm run verify`. Tests must use temporary data and synthetic fixtures. Do not add paid inference or live integration calls to the default suite. Preserve actual failures and distinguish a source observation, model inference, human correction and measured integration outcome.

Keep catalogue research, source provenance, whole-solution adoption and the optional shared canvas aligned. New external connectors must enforce public-network boundaries and bounded responses. Shared-pack changes need privacy sentinel, schema, idempotence and local-overlay preservation checks. Never execute a catalogue candidate's scripts as part of discovery.
